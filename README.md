# 幣圈獵手 LIVE V3

## 這版已改成自動即時
- 打開 App 自動啟動，不需要按掃描
- Binance USDⓈ-M Futures 全市場 24H 成交額篩選
- WebSocket 即時價格（全市場 ticker）
- WebSocket 即時 Funding / Mark Price
- 前 30 個主要標的 Aggregate Trade 即時主動成交流
- OI 每 15 秒刷新，建立約 5 分鐘變化
- 價格 × OI 四象限 LIVE
- 圓點大小代表近期成交活躍度
- 點四象限中的幣可看即時判斷
- 自動分類：偏多候選 / 偏空候選 / 資金潛伏 / 空方潛伏 / 追價風險 / 觀察
- 進場候選榜、資金潛伏榜、全市場榜

## 四象限
- 右上：價格↑ + OI↑ = 多頭增倉
- 左上：價格↑ + OI↓ = 空頭回補
- 左下：價格↓ + OI↓ = 多頭撤退
- 右下：價格↓ + OI↑ = 空頭增倉

## 重要限制
這個版本仍是 GitHub Pages 前端 PWA。
App 開著時可以持續即時更新；iOS 把 App 完全關掉或長時間放到背景後，JavaScript / WebSocket 可能被暫停。
要做到「手機關掉也 24 小時掃描、保留長時間資料、主動推播」需要下一階段的雲端後端服務。

訊號強度是規則引擎評分，不是保證勝率，也不是自動交易建議。
